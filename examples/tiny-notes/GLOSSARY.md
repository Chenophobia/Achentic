# Tiny Notes

A tiny personal note-taking app: write short notes, tag them for later recall.

## Language

**Tag**:
A short label attached to a note by writing `#name` directly inside the note's text. A note's tags are read straight out of its text, not stored separately from it.
_Avoid_: Label, category, hashtag

**Active Filter**:
The single tag currently selected, narrowing the visible notes down to only those containing it. Selecting the same tag again clears it, returning to all notes.
_Avoid_: Selection, current tag, active tag

**Tag Bar**:
The list of every distinct tag found across all notes, shown so a tag can be picked to become the active filter.
_Avoid_: Tag cloud, tag list, tag menu
